# Tranlotek · demo de landing

Demo estática de la nueva landing de tranlotek.com, publicada con GitHub Pages solo para revisión.

- Teléfono, WhatsApp, RUT y correo son **datos provisionales**.
- Las fotografías son **referenciales**, con licencias libres (ver `creditos.html`).
- El formulario funciona en **modo demo**: no envía datos.
- El selector de paleta (abajo a la izquierda) existe solo para el demo.
- No indexable (`noindex` + `robots.txt`).

La versión de producción, con el endpoint PHP del formulario, se despliega en el hosting cPanel.
